THREEK · DOMAIN GUIDE

쓰리케이 홈페이지에
회사 도메인을 연결하는 방법

도메인을 사신 뒤 아래 3단계만 하시면 됩니다. 15분 정도 걸립니다.

지금 홈페이지 확인 주소https://eumsolution.co.kr/threek/
STEP 1

도메인 구매

  1. 가비아(gabia.com)에 회사 명의로 로그인합니다. 후이즈 · 카페24도 방법은 같습니다.
  2. 검색창에 원하는 이름을 넣습니다. 예: threekcarbon.com, threek.co.kr
    해외 고객이 보는 영문 홈페이지라 .com을 먼저 찾아보시길 권합니다.
  3. 등록 기간은 1년, 소유자는 쓰리케이(사업자) 명의로 하고 결제합니다. 호스팅 · 메일 같은 추가 상품은 필요 없습니다.
  4. 자동 연장을 켜 두시면 만료로 주소를 잃지 않습니다.

1년 정가 기준 2~3만 원대입니다. 결제 화면에서 기간이 2~3년으로 잡혀 있으면 1년으로 바꾸세요.

STEP 2

DNS 설정 (레코드 5줄 입력)

가비아 My가비아 → 서비스 관리 → 도메인 → DNS 관리 → 설정 → 레코드 수정에서 아래 5줄을 추가하고 저장합니다.

타입호스트값/위치
A@185.199.108.153
A@185.199.109.153
A@185.199.110.153
A@185.199.111.153
CNAMEwwweumsolution.github.io.

TTL은 기본값 그대로 두시면 됩니다. CNAME 값 끝의 점(.)까지 넣어 주세요.

STEP 3

이음솔루션에 도메인 알려주기

산 도메인 주소(예: threekcarbon.com)를 이음솔루션 담당자에게 카톡이나 문자로 보내 주세요. 홈페이지 쪽 연결과 보안 연결(https), 구글 · 네이버 검색 등록은 이음솔루션에서 마무리합니다.

도메인 · DNS는 쓰리케이 계정에서 관리되므로, 도메인의 소유권은 처음부터 쓰리케이에 있습니다. 비밀번호나 결제 정보는 누구에게도 알려 주실 필요가 없습니다.
